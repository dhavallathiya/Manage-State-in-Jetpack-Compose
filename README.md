# How to Manage State in Jetpack Compose

## Overview
This project provides a comprehensive guide on how to manage state in Jetpack Compose, including:
- Using `remember` to persist state on recomposition
- Using `rememberSaveable` to persist state even on configuration changes
- Using `ViewModel` and `LiveData` to hoist state for reusability

## Features
- Explanation of state management in Jetpack Compose
- Code examples for each state management technique
- Practical tips for efficient state management

## Getting Started
To get a local copy up and running, follow these simple steps.

### Prerequisites
- Android Studio installed
- Basic knowledge of Kotlin and Jetpack Compose
